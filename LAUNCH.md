# Bright Batch Coffee — Launch Steps (Charles)

Use this after the design preview is approved. Goal: live Shopify store selling the **12 oz whole-bean** private-label bag.

## Checklist

1. **Create Shopify trial store**  
   Sign up at Shopify, create the store, pick a temporary `*.myshopify.com` URL.

2. **Add product (12 oz whole bean)**  
   - Title: e.g. `12 oz Whole Bean` (or final brand-named SKU)  
   - Description: port copy from the preview product block  
   - Price: set real price (preview used $18–$22 demo range)  
   - Images: real bag photos (replace SVG placeholder art)  
   - Inventory / variants as needed (whole bean first)

3. **Enable Shopify Payments / payments**  
   Turn on Shopify Payments (or approved alternative). Complete business / payout details so checkout can take real orders.

4. **Set shipping zones**  
   Configure zones, rates, and any free-shipping thresholds. Match the customer story: roasted fresh, then shipped to the door.

5. **Connect Liberty Beans private-label / Shopify sync (one-click)**  
   Wire the private-label / roast-and-ship sync so orders fulfill without naming Liberty Beans on the customer storefront. Confirm roast → ship timing and tracking.

6. **Custom domain**  
   Buy or connect the final domain; set primary domain in Shopify; update DNS; enable HTTPS.

7. **Replace placeholder name / logo**  
   - Store name, logo, favicon  
   - Theme colors (cream / espresso / terracotta)  
   - Email + Instagram links  
   - Any remaining “Bright Batch” placeholders if the brand name changed  
   - Remove demo-price badges and “design preview” language

8. **Test order**  
   Place a real test order end-to-end: cart → checkout → payment → sync / roast queue → shipping label / confirmation email. Fix gaps before announcing.

## After launch

- Publish FAQ / shipping / returns policies in Shopify pages + footer  
- Confirm customer-facing copy never names the invisible roastery partner  
- Keep the preview folder as a UX reference for theme iterations
